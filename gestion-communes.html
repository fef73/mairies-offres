Cliquez sur « Charger depuis le site » ou « Ouvrir un fichier… ».
Pour publier :
  1. Clique sur « Télécharger communes.json ».
  2. Sur GitHub, dépôt mairies-offres : « Add file → Upload files », dépose le fichier (il remplace l'ancien), puis « Commit changes ».
  3. La modification est visible 1 à 2 minutes plus tard (Ctrl+F5 pour recharger).
Altitude vide = altitude automatique d'Open-Meteo. Le logo est le nom d'un fichier déposé dans le dépôt (ex. logo-73116.png).
